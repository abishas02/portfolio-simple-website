Portfolio Website
This is a simple personal portfolio website built using HTML and basic CSS.
The project is designed to showcase a clean layout and fundamental web development skills.
The website consists of two pages:


Home Page – introduces the portfolio and basic information


Contact Page – provides a way for visitors to get in touch


This project focuses on:


Semantic HTML structure


Basic CSS styling and layout


Simple and responsive design principles


It’s a beginner-level project created to practice front-end fundamentals and build an online presence.
